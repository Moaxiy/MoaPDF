# MoaPDF

MoaPDF 是一款本地运行的 PDF 工具，支持空白页插入、页面删除、拆分、合并、图片转 PDF、PDF 转图片、PDF 转 TXT、TXT/Markdown 转 PDF 和 PDF 压缩。所有处理都在本机完成，不上传文件到服务器。

## 功能

- 可视化页面整理
- 空白页插入
- 页面删除
- PDF 拆分
- PDF 合并
- 图片转 PDF
- PDF 转图片
- PDF 转 TXT
- TXT / Markdown 转 PDF
- PDF 压缩

## 技术栈

- Tauri
- Vite
- PDF.js
- pdf-lib
- jszip
